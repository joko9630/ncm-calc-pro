NCM Calc Pro — 설치형 웹앱

1. ZIP 압축을 풀고 모든 파일을 동일한 폴더에 보관합니다.
2. Netlify Drop, GitHub Pages 등 HTTPS 정적 호스팅에 폴더의 모든 파일을 업로드합니다.
3. 아이폰 Safari로 배포된 HTTPS 주소를 엽니다.
4. 공유 > 홈 화면에 추가를 선택합니다.
5. 최초 접속 후 캐시가 완료되면 오프라인으로 계산할 수 있습니다.

주의: ZIP 자체를 아이폰에서 열어서는 홈 화면 설치 및 서비스워커 오프라인 기능이 동작하지 않습니다.

TS2 가소성품의 NCM 금속 몰수는 명목상 Li_rMO2 질량을 가정해 역산합니다. 실제 TS1 가소성품의 조성·중량 손실이 다르면 오차가 발생합니다.
OS 소성 후 질량은 명목상 Li_rM_totalO2 기준의 이론값입니다.
